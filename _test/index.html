1. O básico: display: grid

CSS Grid transforma um elemento em um grid container. Os filhos diretos viram grid items. 

.container {
  display: grid;
}

2. Definindo tracks (colunas e linhas)

Use grid-template-columns e grid-template-rows para definir o tamanho das tracks.

Unidades importantes

  • fr — fração do espaço livre restante
  • px, rem, % — tamanhos fixos ou relativos
  • auto — tamanho baseado no conteúdo
  • minmax(min, max) — tamanho mínimo e máximo
  • repeat(n, valor) — repete o valor n vezes
.grid {
          display: grid;
          grid-template-columns: 1fr 2fr 1fr;   /* 3 colunas: 25% | 50% | 25% */
          grid-template-rows: 80px auto 80px;  /* 3 linhas */
          }

3. Gaps (espaçamento)

gap, row-gap e column-gap controlam o espaço entre os items (não adiciona espaço nas bordas externas). 


            .grid {
            gap: 1rem;           /* igual para linhas e colunas */
            row-gap: 1.5rem;     /* só entre linhas */
            column-gap: 1rem;    /* só entre colunas */
            }

4. Posicionamento dos items

Você pode controlar exatamente onde cada item fica usando grid-column e grid-row. 

          
          .item {
          grid-column: 1 / 3;   /* começa na linha 1, termina na 3 (ocupa 2 colunas) */
          grid-row: 1 / 2;
          /* ou forma curta: */
          grid-column: span 2;  /* ocupa 2 colunas a partir da posição automática */
          }

5. Grid Template Areas (o mais poderoso)

Nomeie as áreas e monte o layout como um desenho ASCII. Ideal para layouts de página (header, sidebar, main, footer). 

.page {
  display: grid;
  grid-template-columns: 200px 1fr;
  grid-template-rows: auto 1fr auto;
  grid-template-areas:
    "header  header"
    "sidebar main"
    "footer  footer";
}

.header  { grid-area: header; }
.sidebar { grid-area: sidebar; }
.main    { grid-area: main; }
.footer  { grid-area: footer; }

6. Alinhamento

Grid tem duas dimensões: inline (horizontal) e block (vertical).

  • justify-items / align-items → alinha os items dentro da célula
  • justify-content / align-content → alinha o grid inteiro quando sobra espaço
  • justify-self / align-self → sobrescreve para um item específico

7. Grid responsivo

A forma mais moderna e elegante: combine repeat() + auto-fit / auto-fill + minmax(). 

.grid {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(220px, 1fr));
  gap: 1rem;
}

Isso cria quantas colunas couberem, cada uma com no mínimo 220px. Redimensione a janela para ver o efeito.

8. auto-fit vs auto-fill

Ambos criam quantas tracks forem necessárias. A diferença aparece quando sobra espaço:

  • auto-fill — mantém as tracks vazias (não estica os items)
  • auto-fit — colapsa tracks vazias e deixa os items crescerem
